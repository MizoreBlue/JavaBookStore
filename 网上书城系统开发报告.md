# 网上书城系统开发报告

## 第1章 绪论

### 1.1 系统开发目的

随着互联网技术的快速发展和电子商务的普及，传统实体书店面临着巨大的转型压力。本项目旨在开发一个功能完善的网上书城系统，为用户提供便捷的在线图书购买平台，同时为管理员提供高效的后台管理功能。

系统开发的主要目的包括：
- 为读者提供24小时不间断的在线购书服务
- 实现图书信息的数字化管理和展示
- 简化购书流程，提升用户体验
- 为书店经营者提供低成本、高效率的销售渠道
- 通过数据分析辅助经营决策

### 1.2 应用场景

本系统适用于以下场景：
- **中小型书店**：为传统书店提供线上销售渠道，扩大业务范围
- **出版社直销**：出版社可直接面向读者销售图书
- **校园书店**：为高校师生提供教材、参考书的在线购买服务
- **个人创业者**：降低创业门槛，快速搭建图书销售平台

### 1.3 实际意义

**对用户而言：**
- 突破时间和空间限制，随时随地浏览和购买图书
- 快速获取图书详细信息，包括简介、价格、库存等
- 通过购物车批量管理商品，简化购买流程
- 查看订单历史，方便追踪和管理

**对商家而言：**
- 降低实体店面租金和人力成本
- 扩大销售范围，覆盖更广泛的客户群体
- 实现库存的实时监控和管理
- 通过销售数据分析优化经营策略

### 1.4 发展现状与存在问题

**发展现状：**
当前图书电商市场已形成以当当网、京东图书等大型平台为主导的格局。这些平台功能完善、用户量大，但也存在以下问题：
- 系统复杂度高，中小型商家难以快速部署
- 平台抽成比例高，压缩商家利润空间
- 个性化需求难以满足

**存在问题：**
1. **技术层面**：部分中小型书店仍采用传统的管理方式，信息化程度低
2. **用户体验**：一些小型系统界面设计简陋，交互体验差
3. **功能完整性**：部分系统功能单一，缺乏完整的购物流程
4. **数据安全**：用户信息和交易数据的安全保障不足

### 1.5 系统开发的必要性和价值

基于上述分析，开发一个轻量级、功能完整的网上书城系统具有重要的现实意义：

1. **技术价值**：采用主流的Java Web技术栈（Servlet+JSP+MySQL），为类似项目提供可参考的技术方案
2. **商业价值**：为中小型书店提供低成本、易部署的电商解决方案
3. **教育价值**：作为Web程序设计的实践案例，帮助理解MVC架构和分层设计思想
4. **社会价值**：促进图书销售数字化转型，推动全民阅读

## 第2章 需求分析

### 2.1 项目总体介绍

#### 2.1.1 项目背景

本项目是Web程序设计课程的实践项目，旨在通过开发一个完整的网上书城系统，综合运用Servlet、JSP、JDBC等技术，掌握Java Web应用开发的核心技能。

#### 2.1.2 目标用户群体

**前台用户（消费者）：**
- 普通读者：浏览、搜索、购买图书
- 注册用户：享受购物车、订单管理等个性化服务

**后台用户（管理员）：**
- 系统管理员：管理图书、分类、订单、用户等

#### 2.1.3 核心业务流程

```
用户注册/登录 → 浏览图书 → 加入购物车 → 提交订单 → 支付（模拟）→ 查看订单
```

#### 2.1.4 系统总体目标

- 实现完整的B2C图书销售流程
- 提供友好的用户界面和良好的交互体验
- 实现高效的后台管理功能
- 保证系统的稳定性和数据安全性

### 2.2 系统功能模块分析

#### 2.2.1 前台功能模块

**1. 用户管理模块**
- **用户注册**：填写用户名、密码、手机号、邮箱等信息
- **用户登录**：验证用户名和密码
- **个人信息管理**：修改个人信息、查看个人资料
- **用户登出**：清除会话，退出系统

**2. 图书浏览模块**
- **首页展示**：显示推荐图书、最新上架图书
- **分类浏览**：按图书分类筛选
- **关键字搜索**：根据书名、作者搜索图书
- **图书详情**：查看图书的完整信息

**3. 购物车模块**
- **添加商品**：将图书加入购物车
- **查看购物车**：显示已添加的商品列表
- **修改数量**：调整商品购买数量
- **删除商品**：移除不需要的商品
- **清空购物车**：一次性删除所有商品

**4. 订单管理模块**
- **提交订单**：填写收货信息，确认订单
- **订单列表**：查看历史订单
- **订单详情**：查看订单的详细信息

#### 2.2.2 后台功能模块

**1. 管理员登录模块**
- 管理员身份验证
- 登录状态管理

**2. 图书管理模块**
- **图书列表**：分页显示所有图书
- **添加图书**：录入新图书信息
- **编辑图书**：修改图书信息
- **删除图书**：删除指定图书
- **搜索图书**：按关键字查询

**3. 分类管理模块**
- **分类列表**：显示所有图书分类
- **添加分类**：创建新的图书分类
- **编辑分类**：修改分类信息
- **删除分类**：删除指定分类

**4. 订单管理模块**
- **订单列表**：查看所有订单
- **订单详情**：查看订单详细信息
- **订单状态管理**：更新订单状态

**5. 用户管理模块**
- **用户列表**：显示所有注册用户
- **删除用户**：删除指定用户

**6. 统计分析模块**
- **销售统计**：按分类统计销售额
- **销售报表**：生成Excel格式的销售报表

#### 2.2.3 模块间交互关系

```
用户模块 ──→ 图书模块 ──→ 购物车模块 ──→ 订单模块
   ↑              ↑              ↑              ↓
   └──────────────┴──────────────┴──────────────┘
                      （用户贯穿整个流程）

后台管理模块
   ├── 图书管理 ←→ 分类管理
   ├── 订单管理 ←→ 用户管理
   └── 统计分析 ←→ 订单管理
```

## 第3章 系统设计

### 3.1 系统组成及功能

#### 3.1.1 硬件环境

**开发环境：**
- CPU：Intel Core i5 及以上
- 内存：8GB 及以上
- 硬盘：可用空间 10GB 以上

**服务器环境：**
- CPU：2核及以上
- 内存：4GB 及以上
- 硬盘：20GB 及以上

#### 3.1.2 软件环境

**开发工具：**
- IDE：IntelliJ IDEA / Eclipse
- 构建工具：Maven 3.6+
- 版本控制：Git

**运行环境：**
- 操作系统：Windows 10/11 或 Linux
- JDK版本：Java 17
- 应用服务器：Apache Tomcat 10.x
- 数据库：MySQL 8.0

**技术栈：**
- 后端：Servlet 6.0、JSP、JDBC
- 前端：HTML5、CSS3、JavaScript、JSTL
- 数据库连接池：Druid 1.2.20
- 工具库：Apache Commons DbUtils 1.7、Lombok 1.18.30

#### 3.1.3 系统架构组成

系统采用经典的MVC（Model-View-Controller）架构模式，结合分层设计思想：

**表现层（View）：**
- JSP页面负责数据展示
- 使用JSTL标签库和EL表达式
- CSS样式和JavaScript交互

**控制层（Controller）：**
- Servlet接收和处理请求
- 调用Service层处理业务逻辑
- 转发或重定向到相应视图

**业务层（Service）：**
- 封装业务逻辑
- 调用DAO层进行数据操作
- 事务管理

**持久层（DAO）：**
- 封装数据库操作
- 使用DbUtils简化JDBC编程
- 实现数据的增删改查

**数据层（Database）：**
- MySQL数据库存储数据
- Druid连接池管理数据库连接

### 3.2 数据库的设计

#### 3.2.1 概念结构设计（E-R图）

系统主要实体包括：

**用户实体（User）**
- 属性：用户ID、用户名、密码、手机号、邮箱、性别、头像、注册时间

**图书实体（Book）**
- 属性：图书ID、书名、作者、简介、分类、封面、价格、库存、创建时间

**分类实体（Category）**
- 属性：分类ID、分类名称、类型、排序、状态、创建时间

**订单实体（Order）**
- 属性：订单ID、总金额、收货地址、收货人、电话、用户ID、状态、创建时间

**订单明细实体（OrderDetail）**
- 属性：明细ID、订单ID、图书ID、数量、金额、图片、书名

**购物车实体（Cart）**
- 属性：购物车ID、图书ID、书名、图片、价格、数量、金额

**实体关系：**
- 用户与订单：1对多关系
- 订单与订单明细：1对多关系
- 图书与订单明细：1对多关系
- 图书与分类：多对1关系

#### 3.2.2 逻辑结构设计（关系模式）

根据E-R图转换得到的关系模式：

1. **用户表（user）**
   - 主键：id
   - 唯一约束：username

2. **图书表（book）**
   - 主键：id
   - 外键：category（关联分类表）

3. **分类表（category）**
   - 主键：id

4. **订单表（orders）**
   - 主键：id
   - 外键：user_id（关联用户表）
   - 索引：user_id, status, create_time

5. **订单明细表（order_detail）**
   - 主键：id
   - 外键：order_id（关联订单表）, book_id（关联图书表）
   - 索引：order_id, book_id

#### 3.2.4 数据库设计合理性分析

1. **主键设计**：所有表使用BIGINT类型的自增主键，保证唯一性和效率
2. **数据类型选择**：根据数据特点选择合适的数据类型，如价格使用DECIMAL避免精度丢失
3. **索引优化**：在频繁查询的字段上建立索引，如订单表的user_id、status等
4. **约束设计**：使用NOT NULL、UNIQUE等约束保证数据完整性
5. **扩展性**：预留了update_time、create_user等字段，便于后续功能扩展
6. **字符集**：使用utf8mb4字符集，支持存储emoji等特殊字符

```java
                Long.parseLong(properties.getProperty(

                Long.parseLong(properties.getProperty(
```

```java
package com.mizore.dao.impl;

import com.mizore.dao.UserDAO;
import com.mizore.entity.User;
import com.mizore.utils.DbUtilsConfig;
import com.mizore.utils.DruidUtils;
import org.apache.commons.dbutils.QueryRunner;
import org.apache.commons.dbutils.handlers.ScalarHandler;

import java.sql.SQLException;
import java.time.LocalDateTime;
import java.util.List;

public class UserDAOImpl implements UserDAO {
    private QueryRunner queryRunner = new QueryRunner(DruidUtils.getDataSource());
    
    @Override
    public User findById(Long id) {
        String sql = "SELECT * FROM user WHERE id = ?";
        try {
            return queryRunner.query(sql, 
                DbUtilsConfig.newBeanHandler(User.class), id);
        } catch (SQLException e) {
            throw new RuntimeException(e);
        }
    }
    
    @Override
    public User findByUsername(String username) {
        String sql = "SELECT * FROM user WHERE username = ?";
        try {
            return queryRunner.query(sql, 
                DbUtilsConfig.newBeanHandler(User.class), username);
        } catch (SQLException e) {
            throw new RuntimeException(e);
        }
    }
    
    @Override
    public Long insert(User user) {
        String sql = "INSERT INTO user (username, password, phone, email, " +
                     "sex, avatar, create_time) VALUES (?, ?, ?, ?, ?, ?, ?)";
        try {
            Number key = queryRunner.insert(sql, new ScalarHandler<>(),
                user.getUsername(), user.getPassword(), user.getPhone(),
                user.getEmail(), user.getSex(), user.getAvatar(), 
                user.getCreateTime());
            return key != null ? key.longValue() : null;
        } catch (SQLException e) {
            throw new RuntimeException(e);
        }
    }
    
    @Override
    public boolean update(User user) {
        String sql = "UPDATE user SET phone = ?, email = ?, sex = ?, " +
                     "avatar = ? WHERE id = ?";
        try {
            int rows = queryRunner.update(sql, user.getPhone(), 
                user.getEmail(), user.getSex(), user.getAvatar(), 
                user.getId());
            return rows > 0;
        } catch (SQLException e) {
            throw new RuntimeException(e);
        }
    }
    
    @Override
    public boolean delete(Long id) {
        String sql = "DELETE FROM user WHERE id = ?";
        try {
            int rows = queryRunner.update(sql, id);
            return rows > 0;
        } catch (SQLException e) {
            throw new RuntimeException(e);
        }
    }
    
    @Override
    public List<User> findAll() {
        String sql = "SELECT * FROM user ORDER BY create_time DESC";
        try {
            return queryRunner.query(sql, 
                DbUtilsConfig.newBeanListHandler(User.class));
        } catch (SQLException e) {
            throw new RuntimeException(e);
        }
    }
    
    @Override
    public List<User> page(int pageSize, int offset) {
        String sql = "SELECT * FROM user ORDER BY create_time DESC " +
                     "LIMIT ? OFFSET ?";
        try {
            return queryRunner.query(sql, 
                DbUtilsConfig.newBeanListHandler(User.class), 
                pageSize, offset);
        } catch (SQLException e) {
            throw new RuntimeException(e);
        }
    }
    
    @Override
    public long count() {
        String sql = "SELECT COUNT(*) FROM user";
        try {
            Long count = queryRunner.query(sql, new ScalarHandler<>());
            return count != null ? count : 0;
        } catch (SQLException e) {
            throw new RuntimeException(e);
        }
    }
}
```

```java
package com.mizore.servlet;

import com.mizore.entity.User;
import com.mizore.service.UserService;
import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

import java.io.IOException;
import java.time.LocalDateTime;

@WebServlet("/user")
public class UserServlet extends HttpServlet {
    private UserService userService = new UserService();
    
    @Override
    protected void doGet(HttpServletRequest request, 
                        HttpServletResponse response) 
            throws ServletException, IOException {
        String action = request.getParameter("action");
        
        if ("login".equals(action)) {
            // 显示登录页面
            request.getRequestDispatcher("/WEB-INF/views/front/login.jsp")
                .forward(request, response);
        } else if ("register".equals(action)) {
            // 显示注册页面
            request.getRequestDispatcher("/WEB-INF/views/front/register.jsp")
                .forward(request, response);
        } else if ("logout".equals(action)) {
            // 退出登录
            request.getSession().invalidate();
            response.sendRedirect(request.getContextPath() + "/");
        } else if ("profile".equals(action)) {
            // 显示个人信息
            request.getRequestDispatcher("/WEB-INF/views/front/profile.jsp")
                .forward(request, response);
        }
    }
    
    @Override
    protected void doPost(HttpServletRequest request, 
                         HttpServletResponse response) 
            throws ServletException, IOException {
        String action = request.getParameter("action");
        
        if ("login".equals(action)) {
            // 处理登录
            String username = request.getParameter("username");
            String password = request.getParameter("password");
            
            User user = userService.login(username, password);
            if (user != null) {
                request.getSession().setAttribute("user", user);
                response.sendRedirect(request.getContextPath() + "/");
            } else {
                request.setAttribute("error", "用户名或密码错误");
                request.getRequestDispatcher("/WEB-INF/views/front/login.jsp")
                    .forward(request, response);
            }
        } else if ("register".equals(action)) {
            // 处理注册
            String username = request.getParameter("username");
            String password = request.getParameter("password");
            String phone = request.getParameter("phone");
            String email = request.getParameter("email");
            String sex = request.getParameter("sex");
            
            User user = User.builder()
                .username(username)
                .password(password)
                .phone(phone)
                .email(email)
                .sex(sex)
                .createTime(LocalDateTime.now())
                .build();
            
            boolean success = userService.register(user);
            if (success) {
                response.sendRedirect(request.getContextPath() + 
                    "/user?action=login");
            } else {
                request.setAttribute("error", "注册失败，用户名已存在");
                request.getRequestDispatcher("/WEB-INF/views/front/register.jsp")
                    .forward(request, response);
            }
        } else if ("update".equals(action)) {
            // 更新个人信息
            User user = (User) request.getSession().getAttribute("user");
            user.setPhone(request.getParameter("phone"));
            user.setEmail(request.getParameter("email"));
            user.setSex(request.getParameter("sex"));
            
            boolean success = userService.update(user);
            if (success) {
                request.getSession().setAttribute("user", user);
                request.setAttribute("message", "更新成功");
            } else {
                request.setAttribute("error", "更新失败");
            }
            request.getRequestDispatcher("/WEB-INF/views/front/profile.jsp")
                .forward(request, response);
        }
    }
}
```

```java
                        HttpServletResponse response)

            // 查看图书详情
            Long id = Long.parseLong(request.getParameter("id"));
            Book book = bookService.getById(id);
            if (book != null) {
                request.setAttribute("book", book);

                    .forward(request, response);
            } else {
                response.sendRedirect(request.getContextPath() + "/product");
            }
        } else {
            // 图书列表（支持分类和搜索）
            int page = parseInt(request.getParameter("page"), 1);
            int pageSize = 12;
            String category = request.getParameter("category");
            String keyword = request.getParameter("keyword");
            
            PageResult<Book> pageResult;
            if (category != null && !category.isEmpty()) {
                pageResult = bookService.page(page, pageSize, category, null);
            } else if (keyword != null && !keyword.isEmpty()) {
                pageResult = bookService.page(page, pageSize, null, keyword);
            } else {
                pageResult = bookService.page(page, pageSize, null, null);
            }
            
            List<Category> categories = categoryService.list();
            
            request.setAttribute("pageResult", pageResult);
            request.setAttribute("categories", categories);
            request.setAttribute("currentCategory", category);
            request.setAttribute("keyword", keyword);
            
            request.getRequestDispatcher("/WEB-INF/views/front/product_list.jsp")
                .forward(request, response);
        }
    }
    
    private int parseInt(String value, int defaultValue) {

            return Integer.parseInt(value);

            return defaultValue;
        }
```

```java
package com.mizore.servlet;

import com.mizore.entity.Book;
import com.mizore.entity.Cart;
import com.mizore.service.BookService;
import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import jakarta.servlet.http.HttpSession;

import java.io.IOException;
import java.math.BigDecimal;
import java.util.ArrayList;
import java.util.List;

@WebServlet("/cart")
public class CartServlet extends HttpServlet {
    private BookService bookService = new BookService();
    
    @Override
    protected void doGet(HttpServletRequest request, 
                        HttpServletResponse response) 
            throws ServletException, IOException {
        String action = request.getParameter("action");
        
        if ("view".equals(action) || action == null) {
            // 查看购物车
            request.getRequestDispatcher("/WEB-INF/views/front/cart.jsp")
                .forward(request, response);
        }
    }
    
    @Override
    protected void doPost(HttpServletRequest request, 
                         HttpServletResponse response) 
            throws ServletException, IOException {
        String action = request.getParameter("action");
        HttpSession session = request.getSession();
        
        @SuppressWarnings("unchecked")
        List<Cart> cartList = (List<Cart>) session.getAttribute("cart");
        if (cartList == null) {
            cartList = new ArrayList<>();
        }
        
        if ("add".equals(action)) {
            // 添加商品到购物车
            Long bookId = Long.parseLong(request.getParameter("bookId"));
            int quantity = Integer.parseInt(request.getParameter("quantity"));
            
            Book book = bookService.getById(bookId);
            if (book != null) {
                // 检查是否已存在
                boolean found = false;
                for (Cart cart : cartList) {
                    if (cart.getBookId().equals(bookId)) {
                        cart.setQuantity(cart.getQuantity() + quantity);
                        cart.setAmount(cart.getPrice().multiply(
                            new BigDecimal(cart.getQuantity())));
                        found = true;
                        break;
                    }
                }
                
                // 不存在则添加
                if (!found) {
                    Cart cart = Cart.builder()
                        .bookId(bookId)
                        .name(book.getName())
                        .image(book.getImage())
                        .price(book.getPrice())
                        .quantity(quantity)
                        .amount(book.getPrice().multiply(
                            new BigDecimal(quantity)))
                        .build();
                    cartList.add(cart);
                }
                
                session.setAttribute("cart", cartList);
            }
            
            response.sendRedirect(request.getContextPath() + 
                "/cart?action=view");
            
        } else if ("update".equals(action)) {
            // 更新购物车商品数量
            Long bookId = Long.parseLong(request.getParameter("bookId"));
            int quantity = Integer.parseInt(request.getParameter("quantity"));
            
            for (Cart cart : cartList) {
                if (cart.getBookId().equals(bookId)) {
                    if (quantity <= 0) {
                        cartList.remove(cart);
                    } else {
                        cart.setQuantity(quantity);
                        cart.setAmount(cart.getPrice().multiply(
                            new BigDecimal(quantity)));
                    }
                    break;
                }
            }
            
            session.setAttribute("cart", cartList);
            response.sendRedirect(request.getContextPath() + 
                "/cart?action=view");
            
        } else if ("remove".equals(action)) {
            // 删除购物车商品
            Long bookId = Long.parseLong(request.getParameter("bookId"));
            cartList.removeIf(cart -> cart.getBookId().equals(bookId));
            session.setAttribute("cart", cartList);
            response.sendRedirect(request.getContextPath() + 
                "/cart?action=view");
            
        } else if ("clear".equals(action)) {
            // 清空购物车
            session.removeAttribute("cart");
            response.sendRedirect(request.getContextPath() + 
                "/cart?action=view");
        }
    }
}
```

```java
package com.mizore.dao.impl;

import com.mizore.dao.SalesDAO;
import com.mizore.entity.dto.SalesRankDTO;
import com.mizore.utils.DruidUtils;
import org.apache.commons.dbutils.QueryRunner;
import org.apache.commons.dbutils.handlers.BeanListHandler;

import java.sql.SQLException;
import java.util.List;

public class SalesDAOImpl implements SalesDAO {
    private QueryRunner queryRunner = new QueryRunner(DruidUtils.getDataSource());
    
    @Override
    public List<SalesRankDTO> getSalesByCategory() {
        String sql = "SELECT b.category AS categoryName, " +
                     "SUM(od.number) AS totalQuantity, " +
                     "SUM(od.amount) AS totalAmount " +
                     "FROM order_detail od " +
                     "JOIN book b ON od.book_id = b.id " +
                     "JOIN orders o ON od.order_id = o.id " +
                     "WHERE o.status >= 2 " +
                     "GROUP BY b.category " +
                     "ORDER BY totalAmount DESC";
        try {
            return queryRunner.query(sql, 
                new BeanListHandler<>(SalesRankDTO.class));
        } catch (SQLException e) {
            throw new RuntimeException(e);
        }
    }
    
    @Override
    public List<SalesRankDTO> getSalesRank(int limit) {
        String sql = "SELECT b.name AS bookName, b.author, " +
                     "SUM(od.number) AS totalQuantity, " +
                     "SUM(od.amount) AS totalAmount " +
                     "FROM order_detail od " +
                     "JOIN book b ON od.book_id = b.id " +
                     "JOIN orders o ON od.order_id = o.id " +
                     "WHERE o.status >= 2 " +
                     "GROUP BY b.id, b.name, b.author " +
                     "ORDER BY totalAmount DESC " +
                     "LIMIT ?";
        try {
            return queryRunner.query(sql, 
                new BeanListHandler<>(SalesRankDTO.class), limit);
        } catch (SQLException e) {
            throw new RuntimeException(e);
        }
    }
}
```

```java
        rowNum = 1;
        for (SalesRankDTO dto : salesRank) {
            Row row = sheet2.createRow(rowNum++);
            row.createCell(0).setCellValue(rowNum - 1);
            row.createCell(1).setCellValue(dto.getBookName());
            row.createCell(2).setCellValue(dto.getAuthor());
            row.createCell(3).setCellValue(dto.getTotalQuantity());
            row.createCell(4).setCellValue(dto.getTotalAmount().doubleValue());
        }
        
        // 输出Excel文件
        workbook.write(os);
        workbook.close();
    }
}
```

## 第6章 问题、体会与收获

### 6.1 开发过程中遇到的主要问题及解决方案

#### 问题1：数据库连接泄漏

**问题描述：** 系统运行一段时间后，数据库连接池耗尽，无法获取新连接

**原因分析：** 早期代码中手动获取Connection后未及时关闭，导致连接泄漏

**解决方案：** 
- 使用DbUtils的QueryRunner自动管理连接
- 配置Druid连接池的连接检测和回收机制
- 在DAO层统一使用QueryRunner，避免手动管理连接

#### 问题2：中文字符乱码

**问题描述：** 表单提交的数据和数据库中的中文显示为乱码

**原因分析：** 
- 请求和响应未设置字符编码
- 数据库字符集配置不正确

**解决方案：**
- 添加CharacterEncodingFilter统一设置UTF-8编码
- 数据库和表使用utf8mb4字符集
- JDBC连接URL指定characterEncoding=utf-8

#### 问题3：数据库列名与Java属性映射

**问题描述：** 数据库列名使用下划线命名（如user_id），Java属性使用驼峰命名（如userId），导致字段值无法正确映射

**原因分析：** DbUtils默认的BeanProcessor不支持自动转换

**解决方案：**
- 创建DbUtilsConfig工具类
- 使用GenerousBeanProcessor实现下划线到驼峰的自动转换
- 在所有DAO中统一使用自定义的BeanHandler

#### 问题4：Session管理问题

**问题描述：** 用户登录后，部分页面无法获取用户信息

**原因分析：** 
- 未正确设置Session属性
- 重定向后Session丢失

**解决方案：**
- 统一使用request.getSession().setAttribute()设置用户信息
- 确保所有需要用户信息的页面都从Session中获取

#### 问题5：分页功能实现

**问题描述：** 分页功能实现复杂，容易出错

**原因分析：** 需要计算总页数、偏移量等多个参数

**解决方案：**
- 创建PageResult工具类封装分页逻辑
- 在Service层统一处理分页计算
- 提供通用的分页JSP组件
